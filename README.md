# Honeybee Designs — Melissa Bullitt Portfolio

A responsive photography portfolio hosted with GitHub Pages. Visitors can view published photos; the owner can sign in to upload photos, rotate and resize them, edit captions, or remove them.

## Setup
Follow [SETUP.md](./SETUP.md), confirm [config.js](./config.js), and run [supabase-setup.sql](./supabase-setup.sql) in Supabase. Never put a Supabase service-role/secret key in browser code.

## Publish
Open **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**.

**Privacy:** uploaded images are public to visitors.
